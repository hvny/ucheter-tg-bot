# Задачи

## Текущая итерация (MVP-ядро)

- [x] Инфраструктура
  - [x] docker-compose с Postgres (БД `ucheter-bot`, порт хоста 5433 — на 5432 висит локальный PostgreSQL)
  - [x] `drizzle.config.ts` + схема Drizzle (users, categories, transactions)
  - [x] Подключение к БД (`src/db`)
  - [x] Скрипты `db:generate` / `db:migrate` / `db:push`
- [x] Константы и утилиты
  - [x] Дефолтные категории (`lib/constants`)
  - [x] Парсинг/валидация суммы (запятая и точка), форматирование суммы и даты (`lib/utils`)
- [x] Сервисный слой (`lib/services`)
  - [x] users: регистрация + создание дефолтных категорий
  - [x] categories: список (по типу, без архивных), создание
  - [x] transactions: создание
- [x] Команды бота
  - [x] `/start` — регистрация, приветствие
  - [x] `/menu` — inline-меню (реализованные пункты + заглушки)
  - [x] `/add` — пошаговый диалог: тип → категория (или новая) → сумма → комментарий → сохранение
  - [x] `/categories` — просмотр списка + добавление новой
  - [x] `/cancel` — выход из диалога
  - [x] UI-паттерн: редактирование одного сообщения, удаление текстовых сообщений юзера
- [ ] Ручная проверка флоу в Telegram (`/start` → `/add` → проверка записи в БД)

## Потом
