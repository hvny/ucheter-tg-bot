  - [x] Периоды (неделя/месяц/всё время) для истории/статистики/экспорта (`lib/utils/period.ts`)
- [x] Сервисный слой (`lib/services`)
  - [x] users: регистрация + создание дефолтных категорий
  - [x] categories: список (по типу, без архивных), создание, архивирование
  - [x] transactions: создание, список с фильтрами и пагинацией, список без пагинации (для экспорта), сводка по периоду, разбивка по категориям
- [x] Команды бота
  - [x] `/start` — регистрация, приветствие
  - [x] `/menu` — inline-меню
  - [x] `/add` — пошаговый диалог: тип → категория (или новая) → сумма → комментарий → сохранение
  - [x] `/categories` — просмотр списка, добавление, архивирование
  - [x] `/history` — список операций с пагинацией и фильтрами (тип, период, категория)
  - [x] `/stats` — сводка (доход/расход/баланс) + круговая диаграмма по категориям
  - [x] `/export` — выгрузка операций в Excel за выбранный период
  - [x] `/cancel` — выход из диалога
  - [x] UI-паттерн: редактирование одного сообщения, удаление текстовых сообщений юзера
- [x] README.md с описанием бизнес-логики

- [x] Ежедневная загрузка курсов через fetch/node-cron, общая статистика и предпочитаемая валюта

- [x] Pino: структурированные события, безопасные ошибки, длительность обработки и LOG_LEVEL
